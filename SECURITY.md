# Security Policy

VZ-Tool Devil is intended for project inspection and defensive education.

- Treat compatibility reports as heuristics, not proof that a project is safe or will run.
- Review third-party dependencies and installation scripts before running them.
- Do not include credentials, access tokens, private keys, or personal data in reports or issues.
- Only assess systems and data for which you have authorization.
- If reporting a defect, provide a minimal reproduction without secrets or sensitive target details.
